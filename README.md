# Hospital Emergency Room Excel Dashboard

## 📊 Project Overview

An interactive Excel dashboard built to analyze hospital emergency room data and provide insights into patient visits, admission status, age groups, and daily patient trends.
## 📊 Dashboard Preview

![Hospital Emergency Room Dashboard](Hospital_ER_Dashboard_2023_2024.png)

## 🎯 Key Analysis


- Total number of patients
- Daily patient visit trends
- Admission vs. non-admission status
- Patient distribution by age group
- Patient analysis by day
- Key healthcare KPIs

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Conditional Formatting
- Dashboard Design
- Data Visualization

## 📌 Dashboard Highlights

The dashboard provides an interactive view of emergency room activity and helps identify patient trends and patterns through visual KPIs and charts.
